3// BS6.3: CSP/CSV/CST mode-management skeleton (bumpless switching). The
4// library's setpoints carry the full kinematic state every cycle, so a
5// bumpless switch means: at the switch instant the field the next mode hands
6// to the drive equals the drive's current state — no position, velocity, or
7// torque step. This skeleton latches the last emitted setpoints on a switch
8// and asserts the continuity contract; the drive-side handshake (modes of
9// operation / display polling over the object dictionary) is B5 scope in the
10// real-drive context.

35 // Bumpless switch: only defined when the stream is live (a latched

64 switch(mode_) {
65 case OperationMode::csp:
66 return setpoints.position;
67 case OperationMode::csv:
68 return setpoints.velocity;
69 case OperationMode::cst:
70 return setpoints.torque;
71 }
72 return setpoints.position;
73 }
