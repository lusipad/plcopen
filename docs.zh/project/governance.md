# 治理

plcopen 当前是个人 GitHub 命名空间下的单维护者开源项目，不由基金会、公司
委员会或认证机构治理。

## 角色

| 角色 | 权限 |
|---|---|
| 维护者 | 路线与语义裁决、合并、仓库权限、发布授权及对外承诺 |
| 贡献者 | 提案、实现、测试、文档及可核验证据 |
| AI 工具 | 在已批准范围内工作；不是维护者、投票者、签署人或继任者 |

当前 bus factor 为 1，没有第二维护者或指定继任者。

## 决策优先级

1. 仓库操作规则与技能。
2. 规范性合规文档与已知边界。
3. 已接受的架构裁决。
4. 当前项目事实。
5. 当前路线图承诺。
6. 长期愿景。

## 发布与对外承诺

tag、GitHub Release、包发布、许可证变化、安全披露裁决和对外承诺都需要
[权威治理文档](https://github.com/lusipad/plcopen/blob/main/GOVERNANCE.md)
规定的权限。CI 通过本身不会授予这些权限。
