# 组接管连续性语义矩阵（Y7，草案，待批准）

> 状态：**草案，待维护者批准**（2026-07-07 起草）。修复 KB-051：组级
> 普通 aborting 接管把路径剖面从静止重规划——成员速度一拍断崖（实测
> 步进 = 加速度限 20.2×）。目标：组接管获得与单轴 KB-028 对等的运动
> 学连续承诺。

## 定位与不变量

| 合同 | 保持 |
|---|---|
| KB-028 单轴接管 | 不动（本矩阵是它的组级对等物） |
| GroupStop（KB-027） | 不动（已受控） |
| 窗口/blending 路径（KB-032/050） | 不动（已从 s_live 播种） |
| 几何 | 接管点位置连续（现状已满足），本矩阵补速度维 |

## 决策点（v1 提案）

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 1 | 入口速度投影 | aborting 接管时采样成员实时速度向量 v⃗，投影到新路径单位方向：v_entry = max(0, v⃗·d̂_new)；新 1D 剖面从 {0, v_entry, a_proj} 规划（a_proj 同法投影） | 前向分量连续承接，KB-026 求解器直接支持非零入口 |
| 2 | 横向分量语义 | 横向残差 v⃗_lat = v⃗ − v_entry·d̂_new。**若 ‖v⃗_lat‖∞ ≤ 每周期包络（成员加速度限）**：一拍内自然消化，直接接管；**否则自动"受控转向"**：沿原路径按新命令的 Deceleration/Jerk 受控减速至横向分量落入包络的速度点（极限为零速），随后启动新路径 | 不瞬移速度方向（物理诚实）；不引入新几何机器（入口过渡曲线留 v2）；确定性可预测 |
| 3 | 受控转向期间的命令归属 | 转向减速段属于新命令生命周期（新命令 Busy，旧命令即时 CommandAborted——与现状一致）；转向段沿旧几何行进的距离有界且可预计算 | 观察语义无歧义 |
| 4 | 适用面 | 组 linear/circular 的 aborting 接管 + 笛卡尔管线接管（KB-044 记录的"从静止重规划"口径同步升级）+ 笛卡尔窗口 conversion 的入口（KB-050 已从实时状态接续，仅对齐术语） | 一个语义盖全组域 |
| 5 | 回放 | 声明变更：新增黄金场景 `core-group-takeover`（运动中直角/浅角两次接管）；既有语料预计逐位不变（盲区场景本就不存在），若有 diff 按声明变更流程审签 | KB-051 盲区补护栏 |

## 退化与拒绝

| 形态 | 语义 |
|---|---|
| 新命令限位容不下投影入口状态 | 自动受控转向（不拒绝——组级与单轴 KB-028 的"减速进入新包络"精神一致） |
| 转向减速中再次 aborting | 从当前实时状态重新走本矩阵（可重入） |
| 静止接管 | 现状语义不变（v_entry=0 直接启动） |

## 验收指标

| 指标 | 口径 | 门槛 |
|------|------|------|
| 速度连续 | 接管前后成员逐周期速度步进 | ≤ 命令加速度限（KB-051 探测转固定测试） |
| 前向承接 | 浅角接管（对齐 >0.9）入口速度 | ≥ 0.9× 投影值（不白白丢速） |
| 受控转向 | 直角/反向接管 | 全程步进 ≤ 包络，转向距离 = 预计算值 ±1 周期量 |
| 回放 | 既有语料 + 新场景 | 逐位 / 新护栏 |

## 不做（v1）

入口过渡曲线（KB-049 式几何入弯，v2）；窗口/blending 路径改动（已受控）；
同步（gear/cam）从轴接管（KB-019 语义域）。
