# 组接管连续性语义矩阵（Y7，v2 草案，待批准）

> 状态：**linear 组范围已批准**（2026-07-07 维护者算法合同裁决，
> 见 [algorithm-contracts](../design/core/algorithm-contracts.md) §5）；
> circular/笛卡尔扩展**未批**——前置条件 = 曲率链式项（q̇=q_s·ṡ、
> q̈=q_ss·ṡ²+q_s·s̈、q⃛=q_sss·ṡ³+3q_ss·ṡ·s̈+q_s·s⃛）显式进矩阵作限值
> 检查后另批。v1 的"受控转向"方案废弃。修复 KB-051：组级普通 aborting
> 接管把路径剖面从静止重规划——成员速度一拍断崖（实测步进 = 加速度
> 限 20.2×）。目标：组接管获得与单轴 KB-028 对等的运动学连续承诺。

## 数学裁决（评审定调，本矩阵的根）

成员速度向量 q̇ 不平行于新路径切向 t̂ 时，以下三者**不可兼得**：
① 速度连续；② 第一拍即严格落在新直线路径上；③ 无横向速度突变。
**裁决取 ①③，放弃 ②**：接管瞬间起走一段**接管连接段（takeover
connector）**，运动允许处于声明的**接管公差管**内；横向分量经有限
jerk/accel 剖面衰减，汇入后恢复严格路径语义。v1 草案的"沿旧路径受控
减速再转向"废弃——它保 ② 弃行进方向，在"路径准确 vs 速度连续"间
摇摆，且白丢前向速度。

## 决策点（v2 提案）

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 1 | 入口标量速度 | ṡ₀ = ⟨q̇, t̂⟩（投影原值，可负）、a_s0 = ⟨q̈, t̂⟩；沿路 1D 剖面从 {0, ṡ₀, a_s0} 规划到新目标 | 前向分量足额承接不丢速；负投影 = 先减速回头，任意初态 OTG 数学自然（负值场景验收单列） |
| 2 | 横向连接段 | 横向残差状态 (0, q̇−ṡ₀t̂, a_lat) 以**独立横向 jerk/accel 受限剖面**衰减至 (·,0,0)（复用既有 1D 求解器，目标静止）；实际输出 = 沿路剖面 ⊕ 横向剖面叠加；连接段时长 T_lat 有限且预计算 | 横向不瞬移（物理诚实）；无新求解器——正交分解复用既有机器 |
| 3 | 限值预算分割 | 连接段内成员限值按预算系数 β 分割：沿路剖面用 β·限值、横向剖面用 (1−β)·限值（默认 β=0.5，逐轴 L∞ 口径——两剖面同轴分量代数相加，分割保证叠加不超限）；连接段结束恢复全额限值 | 叠加超限的唯一系统性防线；验收以逐周期实测步进断言兜底 |
| 4 | 接管公差管 | 连接段内偏离新直线的横向距离 ≤ R_tube = 横向剖面最大位移（由横向初速/分割后限值解析预计算）；R_tube 可回读；汇入时刻（T_lat 后）起严格在线（横向偏差 ≤1e-9），恢复严格路径语义 | 偏差有界、可声明、可观测——"公差管"是承诺不是事故 |
| 5 | 命令归属与观察语义 | 新命令即时 Busy、旧命令即时 CommandAborted（与现状一致）；连接段属新命令生命周期；对齐接管（q̇ ∥ t̂）连接段退化为零长，第一拍即严格在线 | 观察语义无歧义；退化路径 = 现状直觉 |
| 6 | 适用面（**本批 = linear 组**） | v2.1 批准范围仅组 linear aborting 接管；circular + 笛卡尔管线接管扩展另批（曲率链式项前置，见状态头）——KB-044/KB-050 口径升级随扩展批 | 曲线路径的限值检查含 ṡ² / ṡ³ 曲率项，不写清不批（评审裁决） |
| 7 | 回放 | 声明变更：新增黄金场景 `core-group-takeover`（运动中浅角/直角/反向三次接管）；既有语料预计逐位不变（盲区场景本就不存在），有 diff 按声明变更流程审签 | KB-051 盲区补护栏 |

## 退化与拒绝

| 形态 | 语义 |
|---|---|
| 静止接管 | 现状语义不变（ṡ₀=0、无横向残差，零连接段） |
| 对齐接管（横向残差 ≈0，阈值声明） | 零连接段，直接严格在线 |
| 连接段内再次 aborting | 从当前实时合成状态重入本矩阵（横向残差并入新分解，可重入） |
| 新命令限位极小致 R_tube 超声明上限 | 拒绝口径待定：提案按管上限收紧横向剖面（拉长 T_lat 而非拒绝）——批准时定 |

## 验收指标

| 指标 | 口径 | 门槛 |
|------|------|------|
| 速度连续 | 接管前后成员逐周期速度步进（含连接段全程） | ≤ 命令加速度限 × 周期（KB-051 探测转固定测试） |
| 前向承接 | 浅角接管入口标量速度 | = ⟨q̇, t̂⟩ 精确承接（不再打折截零） |
| 公差管 | 连接段横向偏差实测 vs 解析预计算 R_tube | ≤ R_tube；汇入后横向 ≤1e-9 |
| 叠加不超限 | 连接段逐轴逐周期 vel/acc/jerk | ≤ 全额限值（β 分割的实证兜底） |
| 回放 | 既有语料 + 新场景 | 逐位 / 新护栏 |
