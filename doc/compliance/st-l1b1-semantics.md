## 1. 枚举

### 1.1 声明

```st
TYPE MC_DIRECTION : (current := 0, positive := 1, negative := -1);
END_TYPE
VAR
    direction : MC_DIRECTION := MC_DIRECTION#current;
END_VAR
```

- 枚举成员名在同一枚举内唯一；限定名 `Type#Member` 是规范写法。
- 显式值必须是 `DINT` 可表示的整数；省略值从前一成员值加一。
- 显式值可以重复，重复值比较相等，但成员名称仍各自保留。
- 类型声明只出现在编译单元的类型区，不能在 `VAR` 或语句体中动态声明。
- 底层存储为 `DINT` 值加类型 ID；不向用户暴露裸存储布局。

### 1.2 操作与转换

| 形态 | 语义 |
|------|------|
| 同枚举 `=`/`<>` | 比较底层显式值 |
| 不同枚举比较 | 编译错误 `sema_type_mismatch` |
| 枚举与整数比较/赋值 | 编译错误；必须显式转换 |
| `<EnumType>_TO_DINT` | 按具体枚举类型生成的显式转换，返回成员底层值 |
| `DINT_TO_<EnumType>` | 按具体枚举类型生成的显式转换；值不在成员集合时，常量编译报错，运行值触发 `range_violation` |
| `CASE` 选择子 | 允许枚举；标签必须是同枚举成员，重复值标签编译错误 |
| 算术、位运算、排序比较 | 编译错误 `sema_operand_type_invalid` |
| `BOOL`/其他标量隐式转换 | 禁止，沿 L1a 白名单之外均显式拒绝 |

`CASE` 的 `ELSE` 分支仍按 L0 顺序和单次命中语义执行。枚举值损坏不
静默映射到第一个成员；运行时检查失败锁存 fault，变量保持故障前值。

## 2. 子范围

### 2.1 声明与表示

```st
TYPE Percent : INT (0..100);
END_TYPE
```

- 基础类型只能是 `SINT`、`INT`、`DINT`、`LINT`、`USINT`、`UINT`、
  `UDINT` 或 `ULINT`。
- 下界和上界必须是基础类型可表示的常量，且 `lower <= upper`。
- 子范围值按基础类型存储，类型 ID 只存在于加载期类型信息和符号表。
- 初始化、常量折叠、赋值和显式转换都做范围检查。

### 2.2 检查口径

| 场景 | 语义 |
|------|------|
| 常量越界初始化 | 编译错误 `sema_range_violation` |
| 运行值赋给子范围 | 先按 L1a 显式转换，再检查范围；越界锁存 `range_violation` |
| 子范围赋给基础类型 | 无损时可按 L1a 加宽白名单隐式转换，否则显式转换 |
| 两个相同子范围运算 | 仅相等和排序比较；结果为 `BOOL` |
| 子范围算术 | 结果类型为基础类型，不自动夹紧回子范围 |
| `CASE` 选择子 | 可使用子范围变量，标签必须在基础类型域内 |
| `FOR` 控制变量 | 子范围变量可读；控制变量写入仍遵守 L0 的不可赋值规则 |

运行时越界不是截断、饱和或环绕。fault 锁存前的赋值按 L0 中止点规则
保留，后续 scan 只返回同一 fault，直到 `reset()`。

## 3. 诊断与资源边界

- `sema_range_violation`、`range_violation` 使用新增稳定码，编号登记后永不复用。
- 类型数量、枚举成员数量和类型名长度使用加载期固定上限；超过上限返回
  `capacity_exceeded`，不得让编译器或 VM 分配无界内存。
- 枚举 CASE 和子范围检查的周期成本计入字节码指令预算；不把指令预算
  宣称为墙钟 WCET。
- 任意字节输入仍必须 crash-free；恢复路径必须消费坏 token，沿用 L0 fuzz 纪律。
