# H3 固定基座动力学前馈语义矩阵 v1

> 状态：**已批准（2026-07-25，维护者，按 v1 范围）**。维护者先前明确
> 授权按 D3→D1→H1→T2b→H3 顺序开发，并在 T2b 主线证据闭合后再次要求
> 继续。本矩阵把该授权收敛为 T15/H3 的最小纯数学切片；任何扭矩执行、
> 安全包络或全身动力学扩展仍需另行批准。

## 1. 定位与不变量

H3 v1 在 `core/dyn` 提供固定基座转动串联链的 RNEA 逆动力学：

`tau_ff = inverse_dynamics(q, dq, ddq_ref, gravity)`

它是 L2 级纯数学支撑库，不拥有 AxisGroup、H1 会话、adapter、executor 或
驱动模式。调用方可以把成功结果填入 H1 的 `tau_ff` 字段，但库内不自动
连接、更不消费该扭矩。以下既有合同保持不变：

| 合同 | 保持 |
|------|------|
| ADR-0005 | 人形主通道仍是 H1 全身关节帧；组保持单链，不引入 KinematicTree |
| H1 v2.1 | `tau_ff` 仍只是数据通路；adapter/executor 消费前必须完成 T18 |
| H2 | `kin::SerialChain` 及 L5 六轴 seam 不修改；H3 是并列纯数学模块 |
| RT 规则 | 固定容量、零分配、零锁、无异常、无 OS/墙钟调用 |
| 来源纪律 | 模型参数由调用方或仓库自定测试资产提供，不复制厂商模型 |

## 2. v1 决策

| # | 决策点 | 已批准语义 |
|---|--------|------------|
| 1 | 模型范围 | 每个实例表示 1～8 个转动关节、每关节一个刚体的固定基座串联链；不含移动、棱柱、闭环或分支关节 |
| 2 | 多链口径 | 臂、腿、腰等链由调用方分别实例化并逐链求值；不在 H3 内创建全身树或跨链耦合器 |
| 3 | 关节放置 | 每个刚体声明零位 `parent_to_joint` 刚体变换和在子/关节坐标系表达的单位转轴；当前位姿为零位旋转再绕该轴转 `q`，关节原点不随自身转动平移 |
| 4 | 惯性参数 | 调用方提供质量、关节坐标系中的质心和质心处完整对称惯量张量；不复用仅含对角惯量的 AxisGroup 配置结构 |
| 5 | 单位 | `q/dq/ddq` 分别为 rad、rad/s、rad/s²；长度 m、质量 kg、惯量 kg·m²、重力 m/s²、输出 N·m。H1 每周期单位换算仍属于边界层 |
| 6 | 模型校验 | 构造时验证容量、有限值、右手正交旋转、单位转轴、正质量以及物理可行的对称正定惯量；非法模型保持 `valid()==false` |
| 7 | 求值与原子性 | `inverse_dynamics` 先完整校验模型、指针和所有输入；任一失败返回 `invalid_argument`，输出数组逐位不变；成功后一次性提交全部关节扭矩 |
| 8 | 重力语义 | 调用方传入基座坐标系的重力加速度向量，例如 `{0, 0, -9.81}`；零向量明确表示关闭重力项 |
| 9 | 算法与确定性 | 使用固定上限数组的 O(n) RNEA；循环次数只由 `joint_count` 决定，无迭代收敛、隐藏缓存或运行期配置 |
| 10 | 独立 oracle | 测试层使用独立 ABA 正动力学实现做 `RNEA→ABA` 往返，并以解析摆和势能数值梯度交叉检查；不得用 RNEA 自己生成质量矩阵冒充独立 oracle |
| 11 | 性能门 | Release、严格浮点口径下，六条 8 关节链顺序求值（48 关节总量）平均 `≤10 µs/cycle`；门槛在实现前固定，不按实测结果放宽 |
| 12 | 发布与兼容 | 新头文件进入安装包和 find_package/FetchContent consumer；不新增依赖，不改变现有 public 类型或已发布 `pyplcopen==0.20.0` |

## 3. 拒绝与退化

| 输入/状态 | 结果 |
|-----------|------|
| `joint_count == 0` 或 `> 8` | 模型非法，求值返回 `invalid_argument` |
| 非正交/反射零位旋转，非单位/非有限转轴 | 模型非法 |
| 质量非正，质心非有限，惯量非对称/非正定/违反主惯量三角关系 | 模型非法 |
| `q/dq/ddq/gravity` 任一非有限，或任一指针为空 | `invalid_argument`，输出不变 |
| 合法静态输入 | 返回纯重力补偿扭矩 |
| 合法动态输入 | 返回惯性、科氏/离心和重力项的总和 |
| 多条链 | 调用方逐链求值；任一链失败不允许 H3 自动部分拼接全身输出 |

H3 不做隐式归一化、惯量修补、NaN 归零或部分扭矩提交。参数问题应在
配置阶段暴露，而不是在周期路径中被静默掩盖。

## 4. 验收证据

| 行为 | 硬证据 |
|------|--------|
| 单关节动力学 | 平面摆的惯性项和重力项与闭式公式一致 |
| 双关节耦合 | 2R 平面链的质量矩阵、科氏/离心项和重力项与闭式公式一致 |
| 一般三维链 | 非平行转轴、非零零位旋转和完整惯量张量进入独立 ABA 随机往返 |
| 重力坐标约定 | 一般链的 RNEA 静态扭矩与势能中心差分梯度一致 |
| 原子拒绝 | 每类非法模型/输入均返回 `invalid_argument`，预填输出逐位不变 |
| 确定性与 RT | 相同输入逐位同结果；RT safety scan 覆盖新增头文件 |
| 预算 | Release 6×8 链基准平均 `≤10 µs/cycle`，CI 独立硬门 |
| 消费面 | build-tree、install/find_package 与 FetchContent 均可包含并调用 H3 |
| 回归 | 全量 CTest、fuzz、ARM64/QEMU、clang-tidy、回放与 Python smoke 保持全绿 |

## 5. 显式非目标

- T18 扭矩限幅、速度监督、位置围栏及任何 adapter/executor 扭矩消费；
- `tau_policy + tau_ff` 的库内叠加、钳位或优先级；
- 浮动基座、接触/约束动力学、全身质心/ZMP、步态、WBC、MPC 或 RL；
- KinematicTree、跨链耦合、闭环机构、棱柱关节和固定附加体；
- URDF/MJCF 导入、参数辨识、摩擦/电机/减速器模型和厂商参数资产；
- Python binding、MuJoCo 控制器或真机/功能安全声明。
