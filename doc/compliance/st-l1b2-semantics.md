# ST 批次 L1b2 语义矩阵：ARRAY 与 STRUCT

> 状态：**已实现（2026-07-17）**。本矩阵冻结复合类型的加载期布局、
> 运行期边界检查和初始化语义；验收锚点为
> `plcopen_core_st_l1b2_tests`。

## 0. 范围与不变量

| 项 | 已批准口径 |
|----|------------|
| 范围 | 一至三维定长 `ARRAY`、嵌套 `STRUCT`、常量下标、复合初始化、成员/下标访问与赋值 |
| 表示 | 声明序布局；标量按自身宽度自然对齐，复合类型尾部补齐到最大成员对齐；布局写入产物元数据 |
| 确定性 | 同一源码在 Windows/Linux/ARM64 得到相同逻辑偏移与字节码；不得使用宿主 C++ ABI 布局 |
| RT | 全部存储加载期一次铺设；周期路径不分配，访问和边界检查为 O(1) |
| fault | 编译期可判越界报 `sema_index_out_of_range`；运行下标越界锁存 `range_violation` |

## 1. 决策矩阵

| ID | 决策点 | 已批准语义 |
|----|--------|------------|
| L1b2-D01 | ARRAY 维数 | 支持 1..3 维；每维上下界均为整型常量且 `lower <= upper` |
| L1b2-D02 | 下标类型 | 八种整型及其子范围；不允许 REAL、枚举或隐式变窄 |
| L1b2-D03 | 线性化 | 最右维连续，按声明下界归一化后行主序计算偏移 |
| L1b2-D04 | ARRAY 赋值 | 仅完全相同的元素类型、维数和各维上下界可整值赋值；否则编译错误 |
| L1b2-D05 | STRUCT 名义类型 | 名义类型相等才可整值赋值；字段形状相同不构成兼容 |
| L1b2-D06 | 初始化 | 支持位置初始化与命名字段初始化；不能混用，缺项取类型默认值，重复/多余项编译错误 |
| L1b2-D07 | 嵌套 | ARRAY 元素可为标量、枚举、子范围、STRUCT 或定长字符串；STRUCT 字段可递归包含 ARRAY/STRUCT，但类型定义不得循环 |
| L1b2-D08 | 常量折叠 | 常量下标和成员路径在加载期折叠为固定偏移；动态下标保留每维检查 |
| L1b2-D09 | 比较 | ARRAY/STRUCT 不提供 `=`, `<>` 或排序；需要逐字段比较 |
| L1b2-D10 | VAR_IN_OUT | 复合对象可整体或元素传入，引用范围由 L2b 别名规则约束 |

## 2. 拒绝与诊断

| 形态 | 结果 |
|------|------|
| 零长度维度、维数超过 3、元素总数乘法溢出 | `sema_invalid_array_bounds` |
| 常量下标越界 | `sema_index_out_of_range` |
| 运行下标越界 | scan fault `range_violation`；目标对象保持故障前值 |
| 直接或间接递归 STRUCT | `sema_recursive_type` |
| 不同名 STRUCT/不同边界 ARRAY 整值赋值 | `sema_type_mismatch` |
| 开放数组、动态数组、变长数组 | `unsupported_l1b2_dynamic_array` |

## 3. 容量合同

- 每个 ARRAY 最大 65,536 个元素、最大 3 维；每个 STRUCT 最大 256 字段，
  嵌套深度最大 16。
- 单复合对象、单实例静态区和总程序镜像均受现有加载容量限制；任何乘法、
  对齐或总和溢出均在加载前报 `capacity_exceeded`。
- 布局报告必须列出逻辑大小、对齐、字段/维度和偏移，供测试与调试面消费。

## 4. 验收矩阵

| ID | 验收 | 门槛 |
|----|------|------|
| L1b2-A01 | 1/2/3 维边界、非零下界与行主序 | 手工 oracle 全绿 |
| L1b2-A02 | 动态下标端点与越界 fault | 每种整型下标正反例全绿 |
| L1b2-A03 | STRUCT 声明序布局与嵌套偏移 | 三平台布局 dump 一致 |
| L1b2-A04 | 位置/命名/部分初始化 | 黄金程序 ≥20 |
| L1b2-A05 | 类型循环、容量、溢出与错误恢复 | 稳定诊断且 0 crash |
| L1b2-A06 | fuzz | 结构化输入 ≥100,000，0 crash/UBSan |
| L1b2-A07 | 既有回归 | L0/L1a/L1b1 既有程序语义不回退；当前版本锚点受控刷新 |

## 5. 不做

- 动态数组、开放数组、堆分配容器、指针算术和结构反射不做。
- `UNION`、位域和 C/C++ ABI 互操作布局不做。
- STRING/WSTRING/CHAR 及日期类型由 L1b3 定义；用户 POU 由 L2b 定义。
