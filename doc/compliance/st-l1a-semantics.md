> 状态：**已批准（2026-07-11，维护者，L1a 全范围按草案；实现排在
> executor 双域批次之后）**。本文件是 L 系列批次 L1a 的验收规格
> （normative）。依据：T32（类型系统与转换全语义）、已批准的
> [st-l0-semantics.md](st-l0-semantics.md)（其全部合同为本批次不变量）。
> 出处纪律：IEC 61131-3 类型与转换规则为公开标准知识，本文只引条目、

## 0. 批次拆分提案（本矩阵的第一个决策）

| 决策点 | 提案 | 理由 |
|---|---|---|
| L1 拆分 | L1 拆为 **L1a**（本矩阵：标量数值/位串宇宙 + 转换函数矩阵 + 类型化字面量 + 运算面补全）与 **L1b**（复合类型：ARRAY/STRUCT/枚举/子范围/STRING/CHAR/日期族，另立矩阵） | 一口吞 T32 全域批次过大；标量宇宙 + 转换矩阵是 L1b/L4 的地基，先钉 |
| ANY_* 重载消解 | **推 L4**（随标准函数库）：L1a 转换函数按名字定死源/目标类型（`INT_TO_REAL` 无消解可言），泛型消解机制在引入 ANY 签名函数前不存在 | 砍掉 L1 最大的松散面；T32-① 的"钉死每一格"由转换矩阵承担 |

## 1. 定位与不变量

| 合同 | 保持 |
|---|---|
| L0 全部已批语义（KB-069） | 六类型行为逐位不变：既有黄金程序、回放、确定性锚点哈希在**旧程序不变**（新增类型/运算改变 codegen 的部分按 2.4 口径同提交刷新锚点并声明） |
| L0 严格显式哲学 | 有损转换永不隐式；隐式仅限本矩阵 §3 声明的无损加宽白名单 |
| RT 五禁 / 加载域纪律 | 不变；新增运算全部 O(1) 指令 |
| 诊断/一致性机制 | DiagCode 只增不改号；st-l1a-conformance.yaml 延续 L0 管线 |

## 2. 类型面（L1a 新增 10 标量）

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 2.1 | 有符号整型 | SINT(8)/INT(16，既有)/DINT(32，既有)/LINT(64)，二补码，溢出环绕（KB-069 口径外延） | T32-② 全宽度钉死 |
| 2.2 | 无符号整型 | USINT(8)/UINT(16)/UDINT(32)/ULINT(64)，溢出模 2ⁿ 环绕 | 同上 |
| 2.3 | 位串 | BYTE(8)/WORD(16)/DWORD(32)/LWORD(64)：无数值序语义的位模式类型——支持按位 AND/OR/XOR/NOT、相等比较、位串间加宽；**算术与排序比较 = 编译错误**（要算术先显式转整型） | 位串≠整数是标准的类型哲学；未定义组合显式报错 |
| 2.4 | VM 规范表示 | 有符号：int64 符号扩展规范值；无符号/位串：uint64 零扩展规范值；每运算按声明宽度回卷。栈槽仍 8 字节 | 实现口径入矩阵防分叉 |
| 2.5 | VAR CONSTANT | `VAR CONSTANT ... END_VAR`：编译期常量（必须常量初始化），赋值 = 编译错误，参与常量折叠 | 廉价且是 L1b/L4 用例地基 |

## 3. 隐式转换白名单（唯一的隐式面）

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 3.1 | 无损加宽白名单 | 仅以下隐式且仅单向：有符号链 SINT→INT→DINT→LINT；无符号链 USINT→UINT→UDINT→ULINT；跨符号无损 USINT→INT、UINT→DINT、UDINT→LINT（窄无符号→更宽有符号）；REAL→LREAL；位串加宽 BYTE→WORD→DWORD→LWORD（零扩展）。**其余一切组合显式**（整→浮、浮→整、有↔无符号同宽、TIME↔任何、BOOL↔任何、位串↔整型） | 白名单每条零信息丢失可证明；有损隐式是 PLC 事故源 |
| 3.2 | 混型运算解析 | 二元运算两侧类型不同时：若一侧可经 3.1 白名单加宽到另一侧 → 加宽后按目标类型运算；否则编译错误（保持 L0 的 sema_type_mismatch） | 钉死"每一格"：允许即白名单、否则报错，无第三态 |
| 3.3 | 字面量上下文 | L0 规则外延到全部新类型；无上下文默认不变（整→DINT、实→LREAL）；超目标域 = 编译错误 | 与 L0 连续 |
| 3.4 | 类型化字面量 | `INT#5`、`BYTE#16#FF`、`ULINT#18_446_744_073_709_551_615`、`LREAL#1.5` 等全类型前缀形式；域检查同 3.3；`TIME#` 已有 | 标准形式，消除歧义场景 |

## 4. 转换函数矩阵（机读，T32 核心交付）

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 4.1 | 覆盖面 | 15 类型（8 整 + 4 位串 + REAL/LREAL + BOOL；TIME 见 4.6）两两 `<SRC>_TO_<DST>` 全对照 = **210 格**，每格语义显式声明并机读（`st-l1a-conversions.yaml`：from/to/semantics/边界用例锚点），生成脚本校验矩阵×实现×测试三方一致 | "转换矩阵机读化"就是本批次的验收本体 |
| 4.2 | 整→整 | 加宽：值保持（有符号符号扩展/无符号零扩展）；变窄/跨符号：**按目标宽度截断回卷**（模 2ⁿ，与 KB-069 溢出口径同族），不报错不饱和 | 单一口径贯穿：整型域一律环绕 |
| 4.3 | 浮→整 | **round half to even**（IEEE 默认舍入，双平台确定）后按 4.2 回卷到目标宽度；NaN/±Inf 输入 → **scan fault（新错误码 conversion_invalid）** | 舍入必须钉死；NaN 静默变整数是事故 |
| 4.4 | 整→浮、浮→浮 | 整→REAL/LREAL：IEEE 最近舍入（>2⁵³/2²⁴ 精度损失属 IEEE 语义，声明不报错）；LREAL→REAL：IEEE 最近舍入（溢出得 ±Inf，声明） | IEEE 全程，无自定义魔法 |
| 4.5 | 位串↔整型/位串↔位串 | 位模式重解释：同宽零成本；变窄截断低位；加宽零扩展。BOOL↔位串/整型：TRUE=1/FALSE=0；到 BOOL：**非零即 TRUE**（声明） | 位串转换是重解释不是数值转换 |
| 4.6 | TIME 转换 | 仅 `TIME_TO_LINT` / `LINT_TO_TIME`（纳秒计数直通）两格；其余 TIME 格显式 unsupported（诊断归属 L1b 日期族评估） | TIME=ns int64 是 KB-069 已声明表示 |
| 4.7 | BOOL→数值 | `BOOL_TO_<INT 族>`：0/1 | 标准惯例 |
| 4.8 | TRUNC | `TRUNC`（浮→整向零截断）作为 4.3 的显式配对提供，目标类型族版本 `TRUNC_INT`/`TRUNC_DINT`/`TRUNC_LINT`；NaN/Inf 同 4.3 fault | 舍入/截断两种意图都要有显式拼法 |

## 5. 运算面补全

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 5.1 | TIME 乘除 | `TIME * ANY_INT`、`TIME * ANY_REAL`、`TIME / ANY_INT`、`TIME / ANY_REAL`（Ed3 面）：ns 域计算，实数参与时结果**向零截断到 ns**；除零：整除 fault（同 KB-069）、实除按 IEEE 得 ±Inf 后**转 TIME = fault（conversion_invalid）** | 量化口径与 KB-069 TIME 小数截断一致 |
| 5.2 | `**`（幂） | 仅 REAL/LREAL 底数，指数 ANY_NUM；右结合；实现 = `pow`（平台 libm，**声明跨平台字节码确定但运行值允许平台差异并进 KB**——锚点哈希只锚字节码不锚 pow 结果） | 唯一无法双平台逐位承诺的运算，如实声明而非回避 |
| 5.3 | CONTINUE | 循环内跳过本轮余下语句；循环外 = 编译错误（同 EXIT 口径） | Ed3 补全 |
| 5.4 | 非正式 FB 调用 | `inst(expr1, expr2, ...)`：按输入引脚声明序全量赋值（不允许缺省/混用形参）；输出仍经 `inst.Q` 读 | 标准两种调用形态补齐；混用 = 编译错误 |
| 5.5 | 位串字面量语境 | 基数字面量（16#FF）可作位串类型（位模式，域检查按宽度） | 与 3.3 一致 |

## 6. 退化与拒绝规则（进验收测试）

| 形态 | 语义 |
|---|---|
| 有损组合隐式使用（浮→整、同宽跨符号、位串↔整型混算） | 编译错误 `sema_type_mismatch`，消息指出所需显式函数名 |
| 位串算术/排序比较 | 编译错误 `sema_operand_type_invalid` |
| 转换函数用于未声明格（如 `TIME_TO_REAL`） | 编译错误 `sema_unknown_identifier`（函数不存在——矩阵未列即不存在） |
| 浮→整 NaN/Inf、实除 TIME 得 Inf | scan fault `conversion_invalid`（新 ScanError；中止点前赋值保留，锁存至 reset，KB-069 fault 口径） |
| 类型化字面量超域（`SINT#200`） | 编译错误 `sema_literal_out_of_range` |
| CONTINUE 在循环外 / 非正式调用参数计数不符或混用形参 | 编译错误（专用稳定码） |
