# Cam 曲线语义矩阵 v1（草案）

> （cam 高阶化，BS5）的验收规格（normative 候选）。依据 long-term-plan
> 6.3-#6（存储层兼容线性表、运行层重建换加速度连续）与 T6；任务拆解见
> [phase-b-software-work-breakdown.md](../planning/phase-b-software-work-breakdown.md) BS5。

## 定位与不变量

BS5 = 在**不改变线性表导入格式**的前提下，给 cam 从轴一个加速度连续的
运行层重建，消除 C0 折线的"从轴敲齿"（每个表结点处加速度冲击）。
**不改变以下合同**：

| 合同 | 保持 |
|---|---|
| `CamPoint{master, slave}` 严格递增线性表 | 存储/导入格式逐字节不变 |
| C0 线性模式 | 保留为兼容模式（默认），振动后果文档化（6.3-#6） |
| 从轴 gear/cam 生命周期（KB-019 等） | engage/disengage/aborting 语义不变 |
| RT 禁令 | 重建（系数求解）发生在 engage 时（规划域）；周期路径只做区间定位 + 多项式求值 |

## 决策点（v1 提案）

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 1 | 重建曲线族 | **C2 三次样条段**（每段 4 系数）：非周期表用自然边界（端点二阶导 = 0），周期表用周期边界（首尾位置/速度/加速度全连续）。达成 6.3-#6 的加速度连续目标；quintic 段保留给"节点加速度显式约束/修正正弦族"需求（v2） | 三次样条是 C2 的最小实现（内存 ~3×表点数，符合 6.3-#6 预估）；quintic 的额外自由度 v1 无消费者 |
| 2 | 模式选择 | `CamInCommand.interpolation ∈ {linear(默认), spline}`；linear = 既有 C0 路径逐字节不变（回放护栏） | 兼容模式显式、默认不变 |
| 3 | 重建时机与容量 | engage 时在轴内固定缓冲求解三平对角系统（周期表 Sherman-Morrison 循环消元）；spline 模式表点数上限 64（`invalid_argument` 超限）；linear 模式无新增上限 | 求解 O(n) 一次性、规划域；固定缓冲零分配 |
| 4 | 周期表约束 | spline + periodic 要求首尾 slave 相等（±1e-12），否则 `invalid_argument`——周期样条在错位表上无定义 | 显式优于绕回跳变 |
| 5 | 在线表切换 | cam engaged 状态下允许重新 `cam_in`（aborting 语义照旧接管）；**同相位连续切换**（`cam_switch`）v1 要求切换瞬间两表从轴位置一致（±公差参数），否则 `invalid_argument`；速度/加速度允许受限跳变（显式声明——从轴下一周期起走新表几何） | 位置跳变是事故，速度/加速度小跳变由从轴伺服吸收；平滑过渡桥接（OTG 接管轨迹）留 v2 |
| 6 | 求值成本 | 周期路径：区间定位（线性扫描，同既有实现）+ 三次多项式求值；与 C0 同数量级 | 6.3-#6 |
| 7 | 层位 | 重建与求值在 L4 `exec/sync.h`（`CamSpline`）；模式字段在 L5 `CamInCommand` | 依赖向内 |

## 退化与拒绝规则（显式，进验收测试）

| 形态 | 语义 |
|---|---|
| spline 模式表点数 > 64 | `invalid_argument` |
| spline + periodic 首尾 slave 不等 | `invalid_argument` |
| cam_switch 切换点从轴位置不连续（超公差） | `invalid_argument`（不切换，原表继续） |
| 表非法（非递增/非有限/点数 < 2） | 既有 `valid()` 拒绝路径不变 |
| linear 模式 | 一切既有行为逐字节不变（回放护栏） |

## 验收指标（全部纯软件可验证）

| 指标 | 口径 | 门槛 |
|------|------|------|
| 插值一致性 | spline 曲线过全部表结点 | ≤1e-12 |
| C2 连续 | 结点两侧二阶导（解析求值）之差 | ≤1e-9 |
| 周期连续 | periodic 表绕回处位置/速度/加速度差 | ≤1e-9 |
| 加速度冲击对比 | 同一表 C0 vs spline 从轴驱动的二阶差分峰值 | spline 显著低于 C0（测试断言 spline 无阶跃） |
| 切换连续性 | cam_switch 后从轴位置逐周期连续 | 无跳变（≤公差） |
| 回放 | linear 模式全部既有场景 | 逐位不变 |

## 不做（v1 显式范围外）

- quintic/修正正弦显式曲线段与节点加速度约束（v2）；
- 切换的 OTG 平滑桥接轨迹（v2，可复用 B9 接管机制）；
- cam 数据交换格式（如 VDI 2143 类导入器）——B4 原条目的"导入"部分
  另立（工具域，非运行时）。
