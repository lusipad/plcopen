# ST 批次 L3 语义矩阵：进程映像、定位变量、RETAIN 与 force

> 状态：**已批准，待实现（2026-07-17，维护者）**。本矩阵定义纯软件
> 进程映像与扫描边界合同；内核不执行文件、网络或设备 IO。

## 0. 范围与不变量

| 项 | 已批准口径 |
|----|------------|
| 地址空间 | `%I` 输入、`%Q` 输出、`%M` 内存，支持 X/B/W/D/L 宽度和位地址 |
| 扫描 | scan 开始冻结输入快照，程序读该快照；scan 成功结束时一次发布输出；fault 不发布本扫描输出 |
| 字节序 | 映像规范字节序为 little-endian，位 0 为字节最低有效位；不使用宿主端序 |
| 存储 | 定长双缓冲 + 掩码；加载期解析为偏移，周期路径不解析字符串地址 |
| 责任边界 | executor 搬运设备数据、持久化快照和调度；VM 只消费/产生内存镜像 |

## 1. 定位变量与重叠

| ID | 决策点 | 已批准语义 |
|----|--------|------------|
| L3-D01 | 文法 | `AT %IX0.0`、`%IB0`、`%IW2`、`%ID4`、`%IL8` 及 Q/M 对应形态；类型宽度必须与地址宽度一致 |
| L3-D02 | 位变量 | X 仅绑定 BOOL；位号 0..7；位与包含它的 B/W/D/L 地址重叠视为同一存储 |
| L3-D03 | 重叠写 | 同一项目中任何两个可写 Q/M 定位变量字节或位重叠均编译错误；只读 I 别名允许但必须类型/端序一致 |
| L3-D04 | 对齐 | W/D/L 地址必须分别按 2/4/8 字节对齐；非对齐声明编译错误 |
| L3-D05 | 输入快照 | scan 开始时 executor 提交的完整 I 区复制/交换为当前快照，整个 scan 不变 |
| L3-D06 | 输出提交 | 程序写 shadow Q；正常完成时原子发布版本，fault/预算中止丢弃本扫描 shadow 修改 |
| L3-D07 | M 区 | scan 间持久，程序写立即落 shadow 并在成功结束提交；可选 RETAIN/PERSISTENT 分类 |

## 2. RETAIN、PERSISTENT 与 force

| ID | 决策点 | 已批准语义 |
|----|--------|------------|
| L3-D08 | RETAIN | 快照包含 schema version、项目 fingerprint、变量 ID/类型/长度和值；仅扫描边界导入/导出 |
| L3-D09 | PERSISTENT | 与 RETAIN 同格式但跨完整重新加载保留；fingerprint 不同则按稳定变量 ID 精确匹配，类型/长度不等拒绝该项并报告 |
| L3-D10 | 原子性 | 核提供完整定长 buffer 的 encode/decode；文件原子替换、校验和与介质故障由 executor 负责 |
| L3-D11 | force 优先级 | 扫描输入冻结后应用 force mask；读值和最终发布值均以 force 为最高优先级 |
| L3-D12 | 解除 force | 仅扫描边界生效；解除后 I 立即采用新输入快照，Q/M 采用本扫描程序计算值，不回放旧强制值 |
| L3-D13 | 权限 | I 可 force 读值；Q/M 可 force 读写值；未声明地址、类型不符和部分宽值 force 全部拒绝 |

## 3. 拒绝与容量

| 形态 | 结果 |
|------|------|
| 地址越界/未对齐/宽度类型不符 | 稳定加载期诊断 |
| 可写地址重叠或位/字覆盖 | `sema_process_image_overlap` |
| RETAIN 版本/项目/类型不匹配 | 分项诊断并保持声明初值；不做静默转换 |
| scan 中途 force/解除 | 排队到下一扫描边界；队列满 `capacity_exceeded` |
| 内核文件 IO、设备 IO、动态扩容 | 明确不支持 |

- I/Q/M 各区缺省上限 64 KiB，可编译期调整；force 项 ≤1024，RETAIN 项
  ≤4096；镜像大小与版本槽加载前报告。
- 所有偏移加法和宽度范围使用检查算术；任何溢出均在加载前失败。

## 4. 验收矩阵

| ID | 验收 | 门槛 |
|----|------|------|
| L3-A01 | X/B/W/D/L 地址与端序 | 独立字节数组 oracle 全绿 |
| L3-A02 | 重叠/对齐/范围拒绝 | 每个组合有稳定诊断 |
| L3-A03 | 输入冻结与输出提交 | 并发 executor 冒烟中单 scan 只见一个版本 |
| L3-A04 | fault 输出回滚 | fault 前 Q/M shadow 写不发布；IN_OUT 外部副作用按 L2b 规则另计 |
| L3-A05 | RETAIN/PERSISTENT | round-trip、损坏、版本/类型漂移逐项全绿 |
| L3-A06 | force | I/Q/M 设置、覆盖、解除与边界时序全绿 |
| L3-A07 | RT/并发 | scan 零分配、TSAN 0 报告、版本发布无锁 |
| L3-A08 | fuzz | 地址/快照/force/持久化输入 ≥100,000，0 crash/UBSan |

## 5. 不做

- 设备驱动、现场总线、文件系统、网络持久化和权限认证不在 VM 内实现。
- 地址自动重排、宿主端序映射和旧快照格式迁移器不做；版本不匹配显式拒绝。
- 任务调度归 L5，调试 UI/监控协议归 L7。
