# Part 4 Look-ahead v1 语义矩阵（草案）

> 状态：**已批准（2026-07-05，维护者）；v1 已实现（KB-032）**。本文件是
> Phase A5（look-ahead v1，双向扫描速度前瞻）的验收规格（normative）。
> 验收证据：`plcopen_core_a5_lookahead_tests` + 回放场景
> `core-group-window` / `core-group-blend-v2`。
> 算法基线依据 long-term-plan 6.3-#3 与 T2 策略（梯形级双向扫描 +
> 单调收紧）；windows 容量依据 6.3-#3 推荐基线（默认 128 可配，v1 先取
> 编译期常量 64 以满足 A5 DoD 下限）。

## 定位与不变量

A5 v1 = **KB-031 blending 链的多段化**：解除"已提交链不可扩展"的 v1 边界，
允许连续多个 blending 后继构成前瞻窗口，结点通过速度由双向扫描决定。
**不改变以下已验收合同**：

| 合同 | 保持 |
|---|---|
| `BUFFERED` + `mcTMNone` | 仍为完全停止衔接（v0.x/linear 矩阵合同，不因前瞻而提速） |
| `Aborting` | 仍即时接管（KB-026/KB-028 运动学连续） |
| 单段 blending（KB-031） | 链融合、公差承诺、显式降级、节拍门槛语义不变 |
| 圆弧（KB-030) | v1 前瞻窗口仅含 linear 段；圆弧入窗留 v2 |

## 提案范围（v1）

| 决策点 | 提案 | 理由 |
|---|---|---|
| 窗口构成 | 活动段 + 连续 blending 后继（linear→linear），窗口容量 64 段（编译期常量） | A5 DoD"窗口 ≥64 段"；QueueCapacity 相应扩容 |
| 结点速度上限 | min(相邻两命令速度上限, 过渡曲线曲率限速 √(a/κmax), 双向扫描可达速度)；反折结点 = 0（降级停止） | 6.4 层 2/3 |
| 双向扫描 | 梯形级：前向 v²ᵢ₊₁ ≤ v²ᵢ + 2·a·sᵢ，后向 v²ᵢ ≤ v²ᵢ₊₁ + 2·d·sᵢ₊₁，一遍前向 + 一遍后向，无迭代 | T2/6.7：链式约束传播，构造上无收敛性问题 |
| 单调收紧（批准后澄清） | 结点的**几何速度上限**（曲率限速、命令限速）在拐角创建时冻结、恒不放宽；**已承诺件**（执行中的段剖面与过渡曲线）不回撤；未开始件在每次窗口扩展时全量重规划——终端结点因窗口加深而从 0 升到拐角速度正是前瞻收益本身，不属振荡（T2 反振荡针对逐周期重算的算法；v1 仅在 submit 时重算） |
| 执行形态 | v1 在 submit 时同步重算窗口（O(N) 双向扫描），周期内零计算；异步/摊销留 v2（6.2 双层架构的周期外层） | 64 段扫描为微秒级，submit 属非 RT 路径 |
| 段级剖面 | 结点非零速度衔接经 OTG vt≠0 巡航域精化候选规划（2026-07-05 修复后可用）；短行程结点按可达性收紧到扫描结果以下 | 6.4 层 1 依赖已就绪 |
| 节拍门槛 | 多段窗口**取消** KB-031 的逐结点"优于停车基线"对比，改为结构保证：扫描结果 ≥ 停车方案（结点速度 ≥ 0 且窗口整体时长单调不劣） | 扫描本身即全局近似最优；逐段对比在窗口语义下无定义 |

## 退化与降级规则（显式，进验收测试）

| 形态 | 语义 |
|---|---|
| 结点反折（对齐 < -0.999） | 该结点速度 = 0（停止），链在该结点断开为两个窗口；降级可查 |
| 过渡曲线构造失败/公差不可满足 | 该结点降级为停止衔接，`last_blend_degraded_command()` 报告 |
| 窗口容量满 | 新 blending 后继显式 `capacity_exceeded`，不静默丢弃 |
| 混入非 blending 后继（buffered/aborting） | buffered：窗口在此终结（结点速度 0）；aborting：整链接管（既有合同） |
| 圆弧后继请求 blending | `unsupported`（v2 扩展） |
| GroupStop | 沿已承诺几何受控停车（KB-031 口径），未开始段全部清除 |

## 验收指标（6.5 对齐）

- 密集小线段场景（≥32 段，段长 < 2×过渡区）：循环时间效率相对逐段停车基线可测改善，且相对单段 blending（KB-031 逐段提交）不劣；
- 全窗口路径偏差 ≤ 各结点公差；结点速度序列无振荡（重放窗口滚动时结点上限单调不增）；
- 加速度连续性与 KB-031 同口径；
- 回放黄金场景：≥32 段折线窗口滚动。

## v2 扩展：圆弧入前瞻窗口（已批准 2026-07-05；已实现，KB-033）

> 目标场景：线弧混合轮廓（激光/点胶）不停车。验收证据：
> `plcopen_core_a5_lookahead_tests`（线-弧-线窗口、曲率钳制、不对齐
> 降级、边界错误）+ 回放场景 `core-group-window-arc`。

| 决策点 | 提案 | 理由 |
|---|---|---|
| 窗口成员 | 圆弧段（BORDER，KB-030 全部边界沿用）可经 `blending_low/high` + `mcTMNone` 入窗 | 圆弧的"直通"由切向连续性判定，无公差参数；`mcTMMaxCornerDeviation` + 圆弧仍 `unsupported`（线弧公差带过渡曲线留 v3） |
| 结点语义 | 相邻段端点切向对齐（点积 > 0.999）→ 直通结点：速度 = min(两命令限速, 相邻圆弧段曲率限速, 双向扫描)；不对齐 → **降级为停止结点**（速度 0，`last_blend_degraded_command()` 可查，命令仍执行） | 切向不连续处不停车必然超加速度包络；显式降级而非静默或报错 |
| 圆弧段限速 | 整段 min(欧氏命令速度, √(a_junction·R))，a_junction = 该命令加/减速包络最小值 | 圆弧曲率恒定，向心约束整段生效（6.4 层 3） |
| 几何 | 圆弧段不修剪（trim = 0），线段仅在 linear↔linear 结点被过渡曲线修剪（v1 规则不变） | 弧上修剪属 v3 过渡曲线工程 |
| 扫描 | 弧长参与前向/后向扫描（与线段同一公式，长度 = 弧长） | 梯形级扫描与几何种类无关 |
| 螺旋 | 第三轴及以上线性跟随路径参数（KB-030 口径不变） | — |
| GroupStop | 复合弧长停车覆盖弧段几何 | KB-032 口径推广 |
| 验收 | 线-弧-线直通窗口：弧上逐周期半径误差 ≤1e-9、结点不停车、节拍优于停止基线、加速度连续；不对齐结点停止且可查；回放黄金场景 | 6.5 对齐 |

## 实现记录（2026-07-05，KB-032）

窗口 = `AxisGroup` 内定长段数组（64），每段线性剖面按扫描结点速度经
OTG vt≠0 巡航域精化候选规划，过渡曲线定速整数周期遍历；提交时同步
重算（周期路径零规划）。**声明变更（KB-032）**：单后继 blending 从
KB-031 的整链单剖面（链上限速）改为分段结点限速执行，回放基线升级
`core-group-blend-v2`。构造性节拍门槛保留为"扩展窗口 ≥ 原窗口 +
独立停车段则降级"；首次成链沿用 KB-031 场景语义。稠密极限（截断使
段线长归零）v1 显式降级。

## v2 增补：窗口深度运行期可配（草案，待批准，2026-07-06）

`AxisGroup::set_window_depth(n)`，n ∈ [2, 64]，standby + 空队列守卫（同帧/插件 setter 口径）；窗口段数达到配置值即按既有 `capacity_exceeded` 语义拒绝扩展。默认 64 不变（全部既有回放/验收逐位不变）。摊销执行（周期内分摊重规划）属 executor 阶段（B7），本增补不涉及。

验收：n=4 时第 5 段扩展报 `capacity_exceeded`；默认路径逐位回归。
