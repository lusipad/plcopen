# Part 4 Look-ahead v2 jerk 修正语义

> 状态：**已批准（2026-07-05，维护者）**。本文件扩展已批准的
> [part4-lookahead-semantics.md](part4-lookahead-semantics.md)（KB-032/033），
> 对应 Phase B3 / BS4。依据 long-term-plan T2（jerk 修正）与 6.4 层 2。

## 定位

v1 双向扫描用梯形公式 `v² = v0² + 2as` 估算结点可达速度——**高估**了
jerk 受限下的真实可达值（jerk 相位在同样 Δv 下多走距离）。高估的结点
速度让段内 OTG 剖面落入鼓包域（残差燃烧、时长反而变长）。v2 把扫描
换成**精确 jerk 受限可达速度**。

## 决策点（v1 → v2）

| # | 决策点 | 提案 | 理由 |
|---|--------|------|------|
| 1 | 可达速度求解 | 前向/后向扫描均改为：给定入口速度与段长，求"jerk 受限 ramp 距离 ≤ 段长"的最大出口速度——对既有闭式 `ramp_between` 距离做**有界二分**（上界 = 梯形值，it 恒为上界；48 次迭代）。**放弃离线修正因子表**：v1 架构本就在 submit（非 RT）重算窗口，64 段 × 二分 = 微秒级，直接精确解比因子表更简单更紧（T2 的因子表方案是为在线场景准备的，本架构不需要） | 简单、精确、无表内存；6.2 双层架构吸收成本 |
| 2 | 单调收紧 | 不变（KB-032 口径）：几何上限冻结、已承诺件不回撤、未开始件全量重规划；jerk 修正只会**降低**结点上限，构造性满足"只紧不松" | v2 天然继承 v1 反振荡结构 |
| 3 | 窗口深度 | 维持编译期 64（KB-032）；32-1024 运行期可配随"摊销执行"另立（6.2 周期外层工程化），不属本批 | 深度可配与 jerk 修正正交 |
| 4 | 回放 | **声明变更**：窗口场景结点速度整体下移，黄金基线升级（端点逐位不变；时长变化如实记录——预期部分场景因避开鼓包域反而更短） | 与 KB-032/034 同流程 |

## 验收指标

| 指标 | 口径 | 门槛 |
|------|------|------|
| 保守性 | v2 结点速度 ≤ v1 梯形值（逐结点） | 恒成立 |
| 可达性 | 每段独立 jerk-limited ramp（入口→出口结点速度）距离 ≤ 段长 | ≤ 段长 + 1e-9 |
| 节拍 | 密集折线窗口总时长 vs v1 基线 | 不劣化超过 5%（预期改善），如实记录 |
| 端点 | 全部窗口场景终点 | 逐位不变 |
| 无振荡 | 窗口滚动重放结点上限单调不增 | v1 断言沿用 |

## 实现记录（2026-07-05，BS4.2/BS4.3，KB-039）

- `plan::jerk_reachable_speed`（L3）：梯形值做上界的 48 次有界二分；
  组窗口前向/后向扫描两处替换（`window_rebuild`）。
- 验收：a5 套件新增 5000 例随机保守性/可达性断言 + jerk 主导域咬合
  断言；既有全部窗口验收数字不变（密集折线 825/1200=69%、线弧线
  235/277），**全部回放语料逐位不变**——既有场景结点由拐角曲率/命令
  限速主导，jerk 修正未触及；修正只在 jerk 主导（a/j 大）场景收紧，
  该域此前会把段内 OTG 推入鼓包域。单调收紧结构继承 v1。
