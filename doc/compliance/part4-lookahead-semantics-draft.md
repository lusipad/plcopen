# Part 4 Look-ahead v1 语义矩阵（草案）

> 状态：**草案，未批准**。按硬规则"语义矩阵先行"，本文件是 Phase A5
> （look-ahead v1，双向扫描速度前瞻）的规格提案，**人工批准前不得实现**。
> 算法基线依据 long-term-plan 6.3-#3 与 T2 策略（梯形级双向扫描 +
> 单调收紧）；windows 容量依据 6.3-#3 推荐基线（默认 128 可配，v1 先取
> 编译期常量 64 以满足 A5 DoD 下限）。

## 定位与不变量

A5 v1 = **KB-031 blending 链的多段化**：解除"已提交链不可扩展"的 v1 边界，
允许连续多个 blending 后继构成前瞻窗口，结点通过速度由双向扫描决定。
**不改变以下已验收合同**：

| 合同 | 保持 |
|---|---|
| `BUFFERED` + `mcTMNone` | 仍为完全停止衔接（v0.x/linear 矩阵合同，不因前瞻而提速） |
| `Aborting` | 仍即时接管（KB-026/KB-028 运动学连续） |
| 单段 blending（KB-031） | 链融合、公差承诺、显式降级、节拍门槛语义不变 |
| 圆弧（KB-030) | v1 前瞻窗口仅含 linear 段；圆弧入窗留 v2 |

## 提案范围（v1）

| 决策点 | 提案 | 理由 |
|---|---|---|
| 窗口构成 | 活动段 + 连续 blending 后继（linear→linear），窗口容量 64 段（编译期常量） | A5 DoD"窗口 ≥64 段"；QueueCapacity 相应扩容 |
| 结点速度上限 | min(相邻两命令速度上限, 过渡曲线曲率限速 √(a/κmax), 双向扫描可达速度)；反折结点 = 0（降级停止） | 6.4 层 2/3 |
| 双向扫描 | 梯形级：前向 v²ᵢ₊₁ ≤ v²ᵢ + 2·a·sᵢ，后向 v²ᵢ ≤ v²ᵢ₊₁ + 2·d·sᵢ₊₁，一遍前向 + 一遍后向，无迭代 | T2/6.7：链式约束传播，构造上无收敛性问题 |
| 单调收紧 | 新段入窗只能**降低**已有结点速度上限；已承诺（执行中）段与过渡曲线不回撤 | T2：振荡在构造上被排除 |
| 执行形态 | v1 在 submit 时同步重算窗口（O(N) 双向扫描），周期内零计算；异步/摊销留 v2（6.2 双层架构的周期外层） | 64 段扫描为微秒级，submit 属非 RT 路径 |
| 段级剖面 | 结点非零速度衔接经 OTG vt≠0 巡航域精化候选规划（2026-07-05 修复后可用）；短行程结点按可达性收紧到扫描结果以下 | 6.4 层 1 依赖已就绪 |
| 节拍门槛 | 多段窗口**取消** KB-031 的逐结点"优于停车基线"对比，改为结构保证：扫描结果 ≥ 停车方案（结点速度 ≥ 0 且窗口整体时长单调不劣） | 扫描本身即全局近似最优；逐段对比在窗口语义下无定义 |

## 退化与降级规则（显式，进验收测试）

| 形态 | 语义 |
|---|---|
| 结点反折（对齐 < -0.999） | 该结点速度 = 0（停止），链在该结点断开为两个窗口；降级可查 |
| 过渡曲线构造失败/公差不可满足 | 该结点降级为停止衔接，`last_blend_degraded_command()` 报告 |
| 窗口容量满 | 新 blending 后继显式 `capacity_exceeded`，不静默丢弃 |
| 混入非 blending 后继（buffered/aborting） | buffered：窗口在此终结（结点速度 0）；aborting：整链接管（既有合同） |
| 圆弧后继请求 blending | `unsupported`（v2 扩展） |
| GroupStop | 沿已承诺几何受控停车（KB-031 口径），未开始段全部清除 |

## 验收指标（6.5 对齐）

- 密集小线段场景（≥32 段，段长 < 2×过渡区）：循环时间效率相对逐段停车基线可测改善，且相对单段 blending（KB-031 逐段提交）不劣；
- 全窗口路径偏差 ≤ 各结点公差；结点速度序列无振荡（重放窗口滚动时结点上限单调不增）；
- 加速度连续性与 KB-031 同口径；
- 回放黄金场景：≥32 段折线窗口滚动。
