# 采纳与推广计划（2026-07-12）

> 性质：长期规划 0.2 节"采纳与社区 > 证据与信任 > 资金"重心排序的
> 执行拆解。开源本位约束全程有效：灯塔是采纳者不是客户、双许可永久
> 排除、对外承诺与收费属人专属动作、八项硬指标关闭前不用"商用级"
> 字样对外。

## 打法的三个现实前提

1. **无客户 logo，只有可验证证据** → 推广本体 = 把证据变成内容
   （回放逐位门/跨平台字节码哈希/TSAN/对抗探测故事）。Show, don't tell。
2. **第一批采纳者预判是机器人开发者而非传统 PLC 人群**（greenfield、
   无认证包袱，痛点 = 策略与关节间缺确定性执行层——T27 已论证的空位；
   传统设备商属 S2/S3 时间线）。
3. **单人项目渠道只选三个**：HN + r/PLC·r/robotics（国际）、知乎 +
   B站（国内）、开源之夏/COSCon（贡献者管道，兼解 bus factor）。
   其余渠道显式不做。

## 灯塔猎取口径（联合开发交换，非销售）

"你出真机与场景，我出定制批次与优先响应——你得到零授权费、不锁定、
可审计到每行的运动内核，我得到现场证据与公开案例。"价值交换是铁和
案例；现金按资助优先原则另走 Sponsors/基金通道。

## 90 天 KPI（谦虚口径，接长期规划 0.7 表）

PyPI 200-500 下载/月 · stars 200+ · 真实询盘 2-3 · 外部贡献者 1-2。

## 明确不做

付费投放 / 全渠道铺开 / 提前宣称商用级 / 为流量做 feature / 双许可
（VISION 红线）/ 追逐每一个社区热点。
