## 发布定位（对外一段话）

`v0.11.0` 是旧 `src/` 线（v0.x）的**最后一个功能性检查点**：在 Part 1/2
45/45 功能块基线之上，交付 PLCopen Part 4 v2.0 的 ACS 线性运动基础
（`MC_MoveLinearAbsolute` / `MC_MoveLinearRelative`，2-8 轴共享标量路径）。
此后 v0.x 进入 P0-only 维护窗口（见 EOL 公告草案），主线开发转入重写内核
`core/`（v1 纪元）。本版本为 source-only 发布，不承诺 ABI 稳定。

## Release Notes 草稿

### 新增

- PLCopen Part 4 v2.0 线性运动合同矩阵（[matrix](../compliance/plcopen-motion-part4-linear-matrix.md)，22 项：19 implemented / 3 显式 out-of-scope）与公共类型：固定容量 8 轴 `MC_POS_REF` / `MC_DISTANCE_REF`、`MC_COMMAND_ID`、transition velocity、orientation mode。
- 共享标量路径 `GroupLinearPlanner` + Scheduler 驱动的组命令队列；ACS 下 `MC_MoveLinearAbsolute` / `MC_MoveLinearRelative`。
- 2/3/8 轴共线、Absolute/Relative、Aborting/Buffered、CommandAccepted/CommandID、成员限制、GroupStop、错误传播与 scheduler 生命周期回归；`group_linear_move` demo；consumer smoke 扩展为真实两轴线性运动。

### 变更

- `MC_GroupStop` 按 `Deceleration`/`Jerk` 沿 active 组路径受控停止，全员 Standstill 后置 `Done`，`Execute` 保持时维持 GroupStopping；GroupDisable/成员掉电经 `CommandAborted` 结束停止命令。
- 组线性 FB 按当前 `CommandID` 过滤异步回调（`CommandAccepted` 后可复用实例）。
- `Scheduler::release()`/析构先安全脱离存活 `AxesGroup`；频率校验拒绝 NaN/Inf。

### 已知边界

`KB-001`..`KB-018`（README 已知边界节）；Part 4 范围边界见 `KB-012`
（仅 ACS、零过渡、无 kinematics/圆弧/look-ahead）。
