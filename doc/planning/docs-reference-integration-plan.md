# 技术参考页站内整合计划

> 状态：2026-07-24 按“继续整合其他文档页”实施。

## 1. 最可能调整的决定

### 公开信息架构

```text
参考
├─ 算法白盒
├─ 功能块参考
├─ ST 运行时
├─ 标准与证据
├─ 架构决策
└─ C++ API
```

- **置信度：高**
- 新增三对双语站内导读页，分别承接 ST、合规证据和 ADR 的用户任务。
- 现有快速开始、迁移与项目架构页优先链接站内导读；规范、矩阵和 ADR 原文
  继续回链仓库中的权威文件。
- **会推翻此决定的证据**：维护者要求逐页完整翻译全部 `doc/`，或要求把内部
  规划、实施记录与归档材料进入普通用户导航。

### 内容边界

- 三页只解释如何理解和进入权威资料，不复制完整规范矩阵、时效性 CI 长表或
  法务裁决。
- 实现期核对发现英文站仍有五页完整中文正文；本批一并翻译现有实时集成、
  调参、迁移、运维与功能块参考，并把“英文正文不得含中文叙述”纳入合同。
- 浏览器 QA 发现深层页语言选择器仍返回两套首页；本批修为保持 `page.url`
  的同页切换。head 中的站点级 alternate 保持两套根路径，供 Material 跨语言
  搜索装载 sitemap。
- `doc/planning/`、`doc/archive/`、`doc/vision/` 继续不进入普通用户导航。
- **置信度：高**
- **会推翻此决定的证据**：出现明确的外部用户任务，且现有导读无法支持该任务。

## 2. 假设

- 本轮“继续”沿用上一批网站文档整合范围，而不是启动受人类前置阻塞的
  EtherCAT/H1/H3 产品批次。置信度高，来源：对话上下文与 ROADMAP 当前承诺。
- 中英文站继续使用相同相对路径。置信度高，来源：现有 i18n 合同。
- 仓库原文继续是唯一权威源；英文页采用忠实导读，不制造第二套规范。
  置信度高，来源：上一批已批准的文档分层。

## 3. 偏离策略

- 遇到易漂移的数量或状态时，优先链接权威总账，不在导读页复制长表。
- 遇到法务、认证或硬件结论时，只陈述仓库已批准边界，不作新裁决。
- 只有需要改变公开 URL、引入依赖或复制规范形成双重事实源时停止并重新校准。

## 4. 机械工作（低评审价值）

- 增加 ST 运行时、标准与证据、架构决策三对页面。
- 修正五个既有英文页面的中文正文。
- 增加最小 Material 模板覆盖，让语言选择器和 hreflang 保持当前页面路径。
- 更新中英文导航和现有页面中的站外入口。
- 扩展 i18n 验证器，锁定三页、导航、权威源回链和英文正文语言。
- 更新 Changelog、规划索引、CI 证据和实施记录。
