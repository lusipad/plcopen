## 发布形式

### 1. GitHub Release（主发布页）

- 普通 0.x 版本：`v0.20.0`，发布后标记为 Latest，不标记 prerelease；
  “非 prerelease”不等于 1.0 稳定性承诺。
- C++ 交付：GitHub 自动生成的 source `.zip` / `.tar.gz`，其中包含
  C++17 header-only 新核、CMake install/export、Conan recipe 与消费示例。
- 不附加 Windows/Linux/macOS 的 C++ 二进制安装器。header-only 库没有
  必要制造平台二进制矩阵，源码包才是可复现、可审计的交付物。
- vcpkg 清单仍是草稿，Conan recipe 仍需用户从源码创建；本次不宣称已进入
  vcpkg/ConanCenter 公共仓库。

### 2. PyPI（Python 消费入口）

- 包：`pyplcopen==0.20.0`。
- 资产：CPython 3.10～3.13 的 Windows、manylinux x86_64、macOS x86_64/
  arm64 wheels，以及一个 sdist。
- tag 推送触发 `.github/workflows/wheels.yml`，通过 Trusted Publishing/OIDC
  发布，不保存长期 PyPI token。
- Trusted Publisher 与 GitHub `pypi` environment 已配置；发布通过 OIDC
  完成，仓库未保存长期 PyPI token。

### 3. 文档站

- 文档继续发布到 <http://lusipad.com/plcopen/>。
- Release notes 链接 STATUS、CHANGELOG、迁移指南、已知边界和商用证据总账；
