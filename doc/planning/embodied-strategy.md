## 一句话战略

**工业纪律做内核（护城河），具身生态做分发（楔子），人形做北极星
（叙事与会师点），价格观测哨做时钟（触发线决定何时花钱）。**

## 依据：两个世界与一个空档

| 世界 | 强处 | 短板 |
|------|------|------|
| 工业运动控制（PLCopen/Beckhoff/CODESYS） | 值钱、标准化、长周期 | 台架/客户/认证吃日历时间，单人+AI 推不动关键路径 |
| 具身智能（LeRobot/VLA） | 快、开放、零门槛分发 | **没有执行层**：策略 30Hz 直灌舵机，无轨迹整形/安全域/可复现性 |

交叉点定位（今天无人占据）：**"学习栈下面的工业级确定性执行底座"**
——VLA 出意图，plcopen 出周期级 jerk 受限轨迹 + 软限位 + 逐位回放。

## 战略级不做清单

| 不做 | 理由 |
|------|------|
| 自研 RL / 双足平衡算法 | 那是别人的主场；我们是它下面的地板 |
| 硬件军备（买贵机撑门面） | 硬件只买"验证软件的最小载体"或等触发线 |
| 为人形热度挪语言层资源 | 70/20/10 硬约束；L 系列断则护城河断 |
| 绑死 LeRobot | 只依赖其开放物（数据格式/舵机生态），不依赖框架 |
| 宣传跑在证据前 | 每个对外 demo 背后必须站着门禁与回放证据 |

## 风险与对冲

| 风险 | 对冲 |
|------|------|
| 具身热潮退烧 | 地基层价值独立于热点 |
| LeRobot 单点依赖 | 接口开放化（见不做清单） |
| 单人精力分散 | 三层比例写死；人的动作收敛为：批矩阵/下单/对外发声 |
| 迷你人形能力被高估 | 边界已写死（位置舵机=查表步态+太极套路，无跑跳；见 h1-plan §2） |
