## 发布定位（对外一段话）

`v1.0.0-alpha` 是 plcopen 重写内核（`core/`，L0-L7 分层架构）的首个消费入口检查点：
默认 CMake 包目标、install/export、FetchContent、demo 与 Python facade 全部指向新核，
v0.x 公开 FB 面与 pyplcopen 面已全量由新核承接。它**不是**商用级 PLC runtime，不含工业总线实证、实时性证据（72h 抖动报告）或
PLCopen 认证承诺，也不承诺 v1 ABI 稳定（alpha 语义）；kinematics/坐标系/轨迹流等
Phase B 纯软件能力已含（见上方增量）。

## Release Notes 草稿

### 亮点

- **新架构内核**：L0 rt（整型周期时间域、定长容器、SPSC、`-fno-exceptions` 兼容）→
  L1 otg（状态到状态 jerk-limited 规划，oracle + fuzz 门禁）→ L2-L4 几何/规划/执行 →
  L5 单写者轴/组模型 → L6 PLCopen FB 门面。依赖只向内，L0-L4 不含 PLCopen 语义。
- **v0.x FB 面全量承接**：单轴管理/运动、叠加/连续/附加、轨迹表、参数注册表、探针触发、
  数字 IO、DigitalCamSwitch、AxisInfo/MotionState、多轴同步（gear/cam/phasing/combine）、
  组管理与 Part 4 linear。名称与行为映射见[迁移指南](../migration-v0-to-v1.md)。
- **pyplcopen 面全量恢复**：`AxisSim` 与 v0.x 方法集对齐（含 stop/home_position/加速度读回）。
- **验证体系**：19 项 CTest（含 6 个族级验收套件）、OTG oracle + fuzz、RT-safety 静态扫描、
  黄金回放回归（逐周期 setpoint 比对，未声明变更零差异）、微基准趋势、B9-lite 轨迹流 demo。
- **时间最优运动规划（A9 v1）**：离散运动经近时间最优 7 段 jerk-limited S 曲线规划，
  同等约束下运动时长约为保守基线的 65%（KB-026，回放基线 v2）。
- **已声明行为边界编号化**：新核相对 v0.x 的 8 条有意偏离固定为 `KB-019`..`KB-026`
  （README 已知边界节）。

### 破坏性变更

- 默认 `plcopen::plcopen` 为 header-only 新核目标；旧 `src/` 线需显式
  `-DPLCOPEN_BUILD_LEGACY=ON`（安装另需 `PLCOPEN_INSTALL_LEGACY=ON`）。
- 命名空间 `plcopen::core::*`、snake_case 字段、`rt::ErrorCode` 错误码；调度器被显式
  `cycle()` 取代。完整对照表见[迁移指南](../migration-v0-to-v1.md)。

### 已知限制（alpha 边界）

- 无 kinematics、坐标系变换、工业总线（EtherCAT 属 Phase B 独立仓库）。
- 无实时性声明：72h PREEMPT_RT 抖动报告未产出（模板已备，需真机）。
- OTG 求解器为近时间最优 7 段 jerk-limited（A9 v1，随机状态域总时长约为保守基线的 65%，
  百万级 fuzz 门禁）；非零边界加速度的完整 case 枚举是后续项（当前显式报 `unsupported`）。
- 真实硬件 Servo 虚接口未定义（L7 适配层设计项，Phase B5/B7）；当前由 `AxisModel`
  适配器钩子暂代。
- 不承诺 ABI 稳定；PLCopen 认证不在本版本范围。
