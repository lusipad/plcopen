## 3. 测试组织

无孤儿测试；但批次代号命名（a*/r3_*/y7/part4/part5）与模块命名混用，
模块→测试的可发现性弱（要靠 CHANGELOG 解码）。低成本修复：在
`core/test/` 加一份 README 索引表（模块 ↔ 测试文件 ↔ 批次代号），
不重命名文件（免得扰动 CI 与历史）。按名缺口：`exec/`、`plan/path.h`、
`geom/frame.h` 无同名测试（均有间接覆盖），补测试时优先补 exec。
