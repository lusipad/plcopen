# Y0 最优控制 oracle 方法学设计（2026-07-06）

> 目的：给"时间最优"三个字装上标尺——独立参照解算器量化
> `plan_time_optimal` 每个解与理论最优的差距，此后算法极致是趋势线
> 上的数字而非形容词。测试层专用，零运行时成本。

## 1. 问题形式

三重积分器最小时间控制：状态 (p, v, a)，控制 u = jerk，约束
|u| ≤ j_max、|a| ≤ a_max、|v| ≤ v_max，边界 (0, v0, a0) → (d, vt, 0)，
求最小 T*。Pontryagin 极小值原理给出最优控制为 bang-singular-bang
（u ∈ {+j, 0, −j}，饱和段为奇异段），至多 7 段。

## 2. 双 oracle 架构（独立性分层）

**主 oracle：切换结构穷举 + 打靶**（高精度，中独立性）

- 枚举全部合法 jerk 符号模式（≤ ~18 种：3 段符号序列 × 饱和段有无的
  组合，含退化省段）；
- 每种结构下，段时长向量 t⃗ ≥ 0 由边界条件的**联立方程组**解出
  （牛顿法 / 有界二分，与我们求解器的顺序构造法是不同的数学路线）；
- 全部可行解取最小总时长 = T*_shoot。
- 独立性论证：同一 7 段理论，但"联立求根"与"几何构造"的实现错误
  模式不相交；共享的仅是最优结构定理本身。

**副 oracle：状态空间值迭代**（低精度，全独立）

- 归一化问题（j=1, a≤α, v≤β）上做 (p,v,a) 网格反向最小时间值迭代
  （网格 ~160³，测试层跑分钟级，仅小样本集 ~50 例）；
- 精度 ~1-2%，但**不依赖任何最优结构假设**——专抓"两个 7 段实现共享
  同一结构性盲区"的情形；
- 判据：|T*_shoot − T*_dp| ≤ 网格误差界，否则报结构性怀疑。

## 3. 指标定义（进基准趋势）

对分层随机状态集（常规域 / 鼓包域 / 钉边界域 / 高初始加速度域，
各 ≥2500 例）：

```
excess_cycles(case) = our_duration_cycles − ceil(T*_shoot / cycle)
```

- 报告 p50 / p99 / max 的 excess_cycles 分布，按域分层；
- **合法性硬门**：excess_cycles ≥ 0（低于理论最优 = oracle 或我们
  必有一错，立即失败）；
- **质量趋势门**：初始阈值按首测实录（预期常规域 p99 ≤ 2 周期；
  钉边界域现状会难看——这正是 Y2 的靶子），Y2 落地后棘轮收紧。

## 4. 实现边界

- 位置：`core/test/otg_optimality_oracle.cpp`（测试层）+ 每夜档
  全量、PR 档抽样（与既有 fuzz 分层一致）；
- 零外部依赖（牛顿/二分/值迭代全部手写，出处干净）；
- oracle 自证：打靶解回代边界条件 ≤1e-9、约束采样零违例——oracle
  错则一切失效，其自检等级高于被测者。

## 5. 与后续批次的关系

Y0 先行 → Y2（钉边界修复）用 excess_cycles 的钉边界域分布做前后
对照 → T24 快路径的慢路径提速同样以此为尺 → 长期进 KPI（0.7 表
"oracle 最优性差距"项）。
