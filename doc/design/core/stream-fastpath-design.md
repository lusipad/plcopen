## 1. 核心思路：定时五次多项式快解，失败落全解

跟踪稳态的特征：目标以小增量到达，滤波器状态 (p, v, a) 距瞄准状态
(p_aim, v_aim, 0) 很近。此时**固定时长 h（自适应视界）的五次多项式**
从 (p,v,a) 到 (p_aim,v_aim,0) 有闭式系数（~30 flops，零迭代）：

```
q(τ) = 五次 Hermite（边界位置/速度/加速度全约束），τ∈[0,h]
```

快路径流程（每个新目标事件）：

1. 闭式求五次系数（O(1)）；
2. **解析极值校验**（评审修正 2026-07-07：采样近似不得冒充包络
   证明——五次多项式导数族全部低阶，极值点可精确求出）：
   - |q̇| 极值：q̈(τ)=0 的实根（三次，Cardano 闭式按判别式分支，
     确定性零迭代）+ 区间端点；
   - |q̈| 极值：q⃛(τ)=0 的实根（二次，闭式）+ 端点；
   - |q⃛| 极值：q⁗(τ)=0 的根（一次）+ 端点；
   - 逐极值点精确对照限值（仅浮点容差 1+1e-9，**无 0.95 采样
     边距**——不再需要）；成本 ~30 flops，与系数求解同量级；
3. 全部在限 → 接受为当拍剖面（快路径命中）；
4. 任一越限或数值异常（三次判别式病态等）→ 落既有
   `plan_time_optimal` 全解（慢路径，构造性包络保证不变）。

确定性：判据纯函数（闭式根，无迭代），同输入同路径。安全性：接受
的剖面带**解析包络证明**，与全解同级（证明而非抽查）——包络承诺的
证明义务不变，只是多数事件不再支付全解成本。

## 3. 预算账（矩阵门槛依据）

| 场景 | 每关节 | 48 关节 | 对 300µs 门 |
|------|--------|---------|-------------|
| 快路径命中（跟踪稳态/常规摆动） | ~0.5-1µs | 25-50µs | ✅ 大余量 |
| 慢路径（转折/追赶/包络边缘） | ~8.6µs | 413µs | ⚠️ 超门 |
| 混合（命中率 r） | — | 413−363r µs | r≥0.32 即达门 |

- **最坏拍合同（硬门，评审修正 2026-07-07：平均命中率不得替代
  RT 最坏拍设计）**：每周期慢解限流配额 `N_slow`（提案 10）——
  最坏拍 = 48 快解校验 ~50µs + 10 慢解 ~86µs + 采样 ≈ **150µs 级
  < 300µs 门**，任何输入下成立（含全 48 关节同拍落慢路径的对抗
  拍）；
- 超配额关节**保持上一剖面继续采样**（在途剖面本就带包络保证，
  延迟重解不破包络），入 FIFO 下拍优先重解——最迟 ⌈48/10⌉=5 拍
  （5ms@1kHz）全部收敛；延迟期间该关节对新目标的响应滞后与跟踪
  误差增量进 H1 修订矩阵**显式声明**（不破包络、不破同拍原子性
  ——同帧内已重解者与延迟者的差异即声明内容）；
- 命中率 ≥90% 降为**观测指标**（趋势线，非验收门）；验收门 =
  最坏拍预算断言（对抗性全慢拍实测 < 300µs）；
- 慢路径本体提速（8.6µs→目标减半）挂 Y2 顺带项，非 v1 前置。

## 4. 与既有语义的相容

- 事件驱动重解合同（KB-035）不变——快路径是重解的一种实现；
- 锁定线性骑行稳态不变（快路径在锁定态退化为原骑行）；
- 位置包络钳位、时间戳拒绝、两级看门狗全部在快慢路径之上，无分支；
- 回放护栏：快路径改变重解输出（等效但不逐位），属**声明变更**——
  因此快路径为**配置开关（默认关）**：H1 修订矩阵批准 + KB 登记 +
  回放口径声明之后，翻默认才允许（流程顺序不可倒置）；既有场景
  在关闭态保持逐位不变。

## 5. 验收设计（进 H1 修订矩阵）

解析极值校验 vs 稠密采样（1e4 点/剖面）对照 fuzz——任何被接受剖面
零越限（零容忍，这是包络证明的实测背书）；最坏拍合同断言（构造
对抗性全慢拍，实测 <300µs + 延迟重解 ≤5 拍收敛）；命中率 fuzz
（三类流 ×1e4 事件，观测指标）；快路径开关两态语义等价测试（终态
一致 ≤1e-9）；48 关节帧基准两口径（稳态/对抗拍）入 STREAM_METRICS。
