# T24 流式快路径设计（H1 前置，2026-07-06）

> 难点：混合帧下 48 关节同拍重解，全解 ≈8.6µs/关节 → 413µs 超
> 300µs@1kHz 预算，且帧模式下是每帧常态。本设计给出增量快路径，
> 是 H1 矩阵修订的技术依据。

## 1. 核心思路：定时五次多项式快解，失败落全解

跟踪稳态的特征：目标以小增量到达，滤波器状态 (p, v, a) 距瞄准状态
(p_aim, v_aim, 0) 很近。此时**固定时长 h（自适应视界）的五次多项式**
从 (p,v,a) 到 (p_aim,v_aim,0) 有闭式系数（~30 flops，零迭代）：

```
q(τ) = 五次 Hermite（边界位置/速度/加速度全约束），τ∈[0,h]
```

快路径流程（每个新目标事件）：

1. 闭式求五次系数（O(1)）；
2. **包络校验**：在 8 个等分点采样 |q̇|,|q̈|,|q⃛|，对照 0.95× 限值
   （安全边距补采样疏漏）；端点条件精确满足（构造保证）；
3. 全部在限 → 接受为当拍剖面（快路径命中）；
4. 任一越限或数值异常 → 落既有 `plan_time_optimal` 全解（慢路径，
   构造性包络保证不变）。

确定性：判据纯函数，同输入同路径。安全性：快路径只接受**带边距的
采样验证**通过者，边缘情形一律走有构造保证的全解——包络承诺的
证明义务不变，只是多数事件不再支付全解成本。

## 2. 剖面表示的结构变更（唯一实质改动）

滤波器现存 `otg::Profile1D`（相位剖面）；五次多项式不可表示为相位
剖面。引入最小变体：

```cpp
struct StreamProfile {            // filter 内部
    bool quintic = false;
    otg::Profile1D phases;        // 慢路径
    double c[6]; std::int64_t h;  // 快路径系数与时长
};
```

周期采样：quintic 分支 = Horner 求值（~10 flops，与相位采样同量级）。
看门狗/断流/接管语义不变（它们消费的是采样出的状态，不关心剖面形态）。

## 3. 预算账（矩阵门槛依据）

| 场景 | 每关节 | 48 关节 | 对 300µs 门 |
|------|--------|---------|-------------|
| 快路径命中（跟踪稳态/常规摆动） | ~0.5-1µs | 25-50µs | ✅ 大余量 |
| 慢路径（转折/追赶/包络边缘） | ~8.6µs | 413µs | ⚠️ 超门 |
| 混合（命中率 r） | — | 413−363r µs | r≥0.32 即达门 |

- **门槛提案**：代表性流（恒速/正弦/滤波噪声"类 RL"三类）快路径
  命中率 ≥90%（fuzz 实测），48 关节帧口径稳态预算 <300µs；
- **对抗性最坏拍**（全 48 关节同拍落慢路径）≈420µs：<1ms 周期不
  超限（无 overrun），仅预算份额瞬时越 30%——**声明为瞬态上界**，
  1kHz 档接受；4kHz 档人形流声明范围外（v1）；
- 慢路径本体提速（8.6µs→目标减半）挂 Y2 顺带项，非 v1 前置。

## 4. 与既有语义的相容

- 事件驱动重解合同（KB-035）不变——快路径是重解的一种实现；
- 锁定线性骑行稳态不变（快路径在锁定态退化为原骑行）；
- 位置包络钳位、时间戳拒绝、两级看门狗全部在快慢路径之上，无分支；
- 回放护栏：既有逐关节口径场景逐位不变要求**放宽为"快路径关闭时
  逐位不变"**——快路径改变重解输出（等效但不逐位），因此快路径为
  **配置开关（默认开）**，回放场景以关闭态录制或重录声明（矩阵定）。

## 5. 验收设计（进 H1 修订矩阵）

命中率 fuzz（三类流 ×1e4 事件）≥90%；快/慢路径输出的包络断言全过；
快路径开关两态语义等价测试（终态一致 ≤1e-9）；48 关节帧基准两口径
（稳态/对抗拍）数字入 STREAM_METRICS。
