# Project documentation

This section brings the public project documents into the documentation site.
Each page is a curated guide to a canonical repository document, not a second
source of truth.

!!! info "Canonical sources"
    Time-sensitive facts, normative contracts, and policy text remain
    authoritative in the repository. Every page in this section links to its
    canonical source.

## What is intentionally not in the site navigation

`doc/planning/` contains active engineering plans, `doc/archive/` contains
historical material, and `doc/compliance/` contains detailed normative
matrices and audit evidence. They remain browsable in the repository, but
they are not mixed into the user-facing learning path.

Use the pages above as stable entry points, then follow their canonical links
when you need the full engineering record.
